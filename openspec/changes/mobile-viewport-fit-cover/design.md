## Context

Текущее состояние: `frontend/index.html` задаёт viewport без `viewport-fit=cover`; контейнеры карты используют `100svh` (сознательный выбор для стабильной высоты, см. `docs/courtmap-design-system.md` §4/§10). CSS уже использует `env(safe-area-inset-*)` для оверлеев, но при отсутствии cover эти insets равны `0`. См. `proposal.md` — Why.

## Goals / Non-Goals

**Goals:**
- Сделать карту полноэкранной на устройствах с вырезом/домашним индикатором без полос по краям.
- Активировать реальные (ненулевые) safe-area insets, чтобы существующие отступы оверлеев работали.
- Сохранить стабильную высоту карты (`100svh`) — без дёрганья при сворачивании адресной строки.

**Non-Goals:**
- Переход на `100dvh`/`100lvh` (остаётся на будущее, если понадобится убрать пустоту при скрытом chrome).
- Нативное PWA/standalone-приложение (`apple-mobile-web-app-capable` и т.п.) — вне рамок.
- Изменение высот контейнеров или логики карты.

## Decisions

- **Добавить `viewport-fit=cover` в viewport meta**, сохранив `interactive-widget=resizes-content`. Это минимальное изменение, которое расширяет layout-viewport на весь экран и активирует `env(safe-area-inset-*)`. Альтернатива (смена `svh` на `dvh`) отклонена: она убирает дёрганье-стабильность, ради которой выбран `svh`.
- **Не менять CSS height-правила** (`100svh` для `#root`/`.app-shell`/`.map-view`). С cover `svh` по-прежнему = small viewport (с развёрнутым chrome), что даёт стабильность и отсутствие обрезания под панелями.
- **Проверить safe-area отступы на устройстве** и, если insets оказались больше ожидаемых, скорректировать буферы (`+16px` и т.п.) в `index.css`. Сейчас буферы уже заложены.
- **`theme-color` оставить** как есть (`#fafafa`/`#121214`) — совпадает с фоном, маскирует полосы до загрузки карты.

## Risks / Trade-offs

- [Risk] Старые браузеры не поддерживают `viewport-fit` → правило игнорируется, поведение как сейчас (полосы). Mitigation: graceful degradation, без регрессий.
- [Risk] С cover insets становятся ненулевыми → оверлеи могут сдвинуться относительно текущего вида. Mitigation: ручная проверка на физическом устройстве (DevTools не воспроизводит notch).
- [Risk] На некоторых Android-браузерах `env(safe-area-inset-*)` остаётся `0` даже с cover → отступы не изменятся, но и регрессии не будет.

## Migration Plan

Редеплой фронтенда (пересборка образа). Откат: убрать `viewport-fit=cover` из meta и пересобрать. Изменений БД/бэкенда нет.
