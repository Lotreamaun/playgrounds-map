## Why

Проект нацелен на to-go формат: никто не заходит с десктопа, основной сценарий — телефон в руке. Текущий интерфейс построен по десктоп-лекалу (плавающие кнопки, полноэкранный своп «Карта/Список», всплывающая 280px-панель формы) и неудобен, медлителен и тесен на мобильном. Нужна оптимизированная, быстрая мобильная версия с учётом UI/UX-эталонов нативных карт.

## What Changes

- **Лейаут «карта + нижняя шторка»**: карта всегда остаётся живой подложкой; карточка площадки, список и форма открываются поверх неё, а не заменяют экран.
- **Bottom sheet** (выдвижная шторка снизу) для карточки площадки и списка: с ручкой, состояниями «peek»/«развёрнуто», drag-жестом, учётом safe-area.
- **Форма добавления** становится полноэкранным модальным окном (снизу), а не плавающей 280px-панелью.
- **Переключатель «Карта/Список» на мобилке убирается** полностью — простое переключение экранов исчезает, список открывается как шторка.
- **Floating Action Button** («Добавить») вместо плавающей кнопки-капли снизу.
- Компактный верхний бар поверх карты; тач-цели ≥ 44px; учёт зоны большого пальца.
- Работа в брейкпоинте ≤ 767px; десктоп и планшеты **BREAKING**: нет, поведение на ≥ 768px остаётся как сейчас.
- **Локализация на русский** видимых строк интерфейса (это в компонентах, дизайн-токены не трогаем).

## Capabilities

### New Capabilities
- `frontend-bottom-sheet`: контейнер мобильного интерфейса — выдвижная шторка снизу (peek/expand, drag-жест, safe-area, modal-вариант) и полное модальное окно формы.

### Modified Capabilities
- `frontend-court-list`: режимы отображения меняются — список становится шторкой поверх карты, своп экранов убирается, сортировка по близости сохраняется.
- `frontend-court-ui`: карточка площадки показывается в нижней шторке; форма добавления открывается полноэкранным модальным окном; строки интерфейса локализуются на русский.
- `frontend-mapping`: компактный верхний бар и FAB поверх карты, locate-контрол в мобильном размещении; карта остаётся подложкой и не перекрывается свопом.

## Impact

- **Frontend** (React): `App.tsx` — новая модель состояния (убрать `view: 'map'|'list'` своп, добавить состояние шторки/модалки); `CourtList.tsx`, `CourtMarker.tsx`/карточка, `CourtForm.tsx` — перенос в шторку/модалку.
- **Новый компонент** bottom sheet (в `frontend/src/components/`).
- **CSS** (`index.css`): медиа-запрос ≤ 767px, safe-area-инсеты, стили шторки/модалки/FAB/верхнего бара. Дизайн-токены в `:root` не меняются.
- **Backend / API**: без изменений.
- **Локализация**: строки в `CourtForm`, `CourtMarker`, карточке, списке переведены на русский.
