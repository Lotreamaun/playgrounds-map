## ADDED Requirements

### Requirement: Lighting choice when adding a court
Форма добавления площадки SHALL позволить пользователю выбрать, есть ли на новой площадке освещение, через переключатель «Есть освещение» рядом с переключателем «Крытая площадка». Значение по умолчанию — выключено, чтобы не менять существующее поведение. При отправке формы через `POST /courts` SHALL передаваться выбранное значение `has_lighting` вместо жёстко заданного `false`. Карточка и список площадок SHALL отображать факта освещения как «Есть» / «Нет» в зависимости от значения `has_lighting`.

#### Scenario: Lighting switched on
- **WHEN** пользователь в форме добавления включает переключатель «Есть освещение» и отправляет форму
- **THEN** через `POST /courts` отправляется `has_lighting: true`, и в карточке созданной площадки отображается «Освещение: Есть»

#### Scenario: Lighting left off by default
- **WHEN** пользователь отправляет форму добавления, не трогая переключатель «Есть освещение»
- **THEN** через `POST /courts` отправляется `has_lighting: false`, и в карточке созданной площадки отображается «Освещение: Нет»
