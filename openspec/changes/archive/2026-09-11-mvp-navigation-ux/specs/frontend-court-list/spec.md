## MODIFIED Requirements

### Requirement: View can switch between map and list
Список площадок SHALL открываться как второстепенный UI поверх постоянно видимой карты — в шторке на мобильном, в боковой панели на desktop — вместо полноэкранного переключения экранов «карта/список». Отдельный переключатель полноэкранных режимов SHALL отсутствовать на любой платформе; карта остаётся видимой подложкой.

#### Scenario: Switch to list view
- **WHEN** пользователь активирует режим «список»
- **THEN** список площадок открывается поверх карты — в шторке на мобильном или в боковой панели на desktop

#### Scenario: Switch back to map view
- **WHEN** пользователь закрывает список
- **THEN** список закрывается, карта остаётся полноэкранной/видимой подложкой, без перезагрузки страницы

#### Scenario: No full-screen page switch on mobile
- **WHEN** пользователь работает на мобильном
- **THEN** переключение между картой и списком не заменяет весь экран отдельной страницей

#### Scenario: No full-screen page switch on desktop
- **WHEN** пользователь работает на desktop
- **THEN** переключение между картой и списком не заменяет весь экран отдельной страницей
