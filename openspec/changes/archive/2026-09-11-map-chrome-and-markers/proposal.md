## Why

`frontend-mapping` уже покрывает базовые требования редизайна из предыдущего change'а (иконка на маркере вместо пустой точки, выделение выбранного маркера, контролы карты в акцентном цвете, отсутствие перекрытия с чужим UI) — но реализация опирается на emoji (`🏀`/`📍`) и плоскую заливку `--accent` для всех видов спорта, а нативные zoom/geolocation-контролы просто перекрашены по иконке на непрозрачном фоне пакета темы. Дизайн-система (`docs/courtmap-design-system.md`) требует: категориальный цвет маркера по виду спорта (не акцент), настоящую иконку из Phosphor Icons (не emoji) с состоянием Regular/Duotone, `.glass-over-map` для контролов, парящих над картой, и синхронизацию светлого/тёмного слоя тайлов Яндекс.Карт с темой приложения — этого сейчас нет.

**Зависимость:** этот change использует токены `--sport-*` и класс `.glass-over-map`, вводимые в change `design-tokens-foundation` — тот должен быть применён (`openspec apply`) первым.

## What Changes

- Маркер площадки: заливка пина переключается с `var(--accent)` на категориальный токен вида спорта (`--sport-basketball` и т.д.); белая обводка 2px и тень, введённые ранее, сохраняются без изменений.
- Иконка внутри маркера: emoji (`🏀`, `📍`) заменяется на Phosphor Icons (`@phosphor-icons/react`, новая зависимость) — вес `Regular` в обычном состоянии, `Duotone` у выбранной площадки (заменяет текущий чисто масштабный highlight, дополняя его сменой веса иконки). Для вида спорта без сопоставленной иконки — нейтральная дефолтная Phosphor-иконка вместо `📍`.
- Кластер маркеров остаётся на `--accent` (без изменений в этом change — он уже не привязан к цвету спорта).
- Нативные контролы карты (zoom, геолокация): контейнер контрола получает `.glass-over-map` (блюр + полупрозрачная графитовая подложка) вместо непрозрачного фона пакета темы; перекраска самой иконки в `--accent`, уже реализованная ранее, сохраняется.
- Слой карты (`YMapDefaultSchemeLayer`) получает `theme` (`'light' | 'dark'`), синхронизированный с темой приложения (`prefers-color-scheme` и/или `[data-theme]`), чтобы тайлы Яндекса не выбивались на фоне тёмного интерфейса.
- **Вне рамок этого изменения:** мультиспортовые иконки сверх уже поддерживаемых видов спорта в данных (задел на будущее, см. дизайн-систему §2.3), кастомизация цвета самих тайлов карты под `--bg` (дизайн-система называет это экспериментальным, не гарантированным API Яндекса).

### Modified Capabilities

## Impact

Frontend only. Затронутые файлы: `frontend/src/components/CourtMarker.tsx` (рендер иконки через Phosphor, категориальный цвет по `sport_type`), `frontend/src/components/MapView.tsx` (`theme` на `YMapDefaultSchemeLayer`, определение текущей темы), `frontend/src/index.css` (заливка `.court-marker__pin` по категориальному токену, `.glass-over-map` на контейнерах `.ymaps3--zoom-control`/`.ymaps3--geolocation-control`), `frontend/package.json` (новая зависимость `@phosphor-icons/react`). Изменений backend/API нет — `sport_type` уже приходит из API без изменений контракта.
