## Why

Сейчас у площадки нет отдельного адреса: в карточке вместо него показывается `description` (или заглушка "Address unavailable"). Для поиска площадок и их отображения в списке (будущий change `court-list-nearby`) нужен настоящий человекочитаемый адрес. Заполнение адреса должно быть удобным: автоматически подставляться из координат и при необходимости корректироваться вручную.

## What Changes

- Добавить в модель Court обязательное/необязательное поле `address: str`, сохранять его при создании через `POST /courts` и возвращать в `GET /courts` и `GET /courts/{id}`
- **BREAKING** для существующей БД: добавление нового столбца в таблицу `courts`; текущая схема `create_all` не делает миграций, потребуется явное решение (см. Impact/design)
- В форме добавления площадки — автоподстановка адреса обратным геокодированием координат клика на карте (Яндекс Геокодер, JS API на фронте) с возможностью ручной правки
- В карточке площадки показывать адрес из поля `address` вместо fallback на `description`
- Типы фронтенда (`src/types/court.ts`) регенерируются из нового backend-контракта

## Capabilities

### New Capabilities
_Нет новых способностей — адрес вливается в существующие._

### Modified Capabilities
- `courts`: модель Court получает поле `address`, которое сохраняется при создании и возвращается в списке и по `GET /courts/{id}`
- `frontend-court-ui`: форма добавления автоматически подставляет адрес по координатам (с ручной коррекцией); карточка площадки показывает `address`

## Impact

- **Backend**: `backend/app/models/court.py` (новое поле), `backend/app/routers/courts.py` (приём/возврат `address`), обновление OpenAPI-схемы
- **Миграция БД**: текущий `SQLModel.metadata.create_all` не изменяет существующие таблицы; для `backend/data/courtmap.db` нужен один из вариантов: Alembic / простая проверка-ALTER при старте / сброс БД (решение — в design.md)
- **Frontend**: `CourtForm.tsx` (геокодер + поле адреса), `CourtMarker.tsx`/карточка (показ address), регенерация `src/types/court.ts`, при необходимости `services/api.ts`
- **Внешний API**: Яндекс Геокодер JS (обратное геокодирование), используется на фронте
